# Интерактивный прототип о Иване Кугаче

Статический HTML-прототип цифрового опыта вокруг работ Ивана Кугача. Текущая версия проверяет не только музейный интерактив, но и более цельную метафору сайта: личная мастерская художника, где есть обрамленные картины, рабочие поверхности, краски, палитры, прислоненные холсты и склад работ.

Проект остается single-file прототипом без сборщика и backend. Основной актуальный файл в корне сейчас: `index_masterskaya.html`.

## Текущее состояние

В актуальной версии собраны:

- посадочный экран в эстетике мастерской;
- сюжетные narrative-вставки между этапами маршрута;
- первый интерактив `Возвращение цвета` на основе `src/Kugach_picture_1.png`;
- второй интерактив `Приблизить детали` на основе `src/Kugach_picture_2.png`;
- экран работ для покупки с каталогом, архивом, статусами, ценами и формами заявки;
- визуальная метафора склада картин для каталога продаж;
- декоративный слой мастерской: настенные рамы, полка с красками, тюбики, банки, прислоненные холсты;
- адаптивные ограничения, чтобы декоративные элементы не мешали мобильной версии.

## Дизайн-направление

Основной визуальный принцип текущего этапа: сайт не выглядит как нейтральная музейная карточка, а ощущается как вход в рабочее пространство художника.

Ключевые решения:

- фон строится как теплая мастерская с деревянной стеной/полом и верхним светом;
- hero-блок и интерактивные области оформлены как картины в рамах;
- карточки запуска и информационные блоки выглядят как листы и материалы на рабочем столе;
- каталог продаж стилизован под склад: работы стоят в рамах, у карточек есть инвентарные бирки и полочная фактура;
- палитра, краски и прислоненные холсты вынесены в отдельный декоративный слой `.studio-props`.

## Основной маршрут

1. Пользователь открывает посадочный экран.
2. Может начать сюжетную линию через верхний CTA или открыть один из сценариев напрямую.
3. Проходит вступительный narrative-блок.
4. Попадает в интерактив `Возвращение цвета`.
5. После завершения может продолжить историю.
6. Проходит промежуточный narrative-блок.
7. Попадает в интерактив `Приблизить детали`.
8. После просмотра всех точек может открыть финальный narrative-блок.
9. Возвращается на главный экран или переходит к работам для покупки.

## Интерактивы

### Возвращение цвета

Первый интерактив работает через `canvas`:

- загружает `src/Kugach_picture_1.png`;
- рисует поверх цветной картины серый слой;
- пользователь стирает серый слой кистью;
- прогресс считается по карте покрытия;
- при достижении порога запускается финальное авто-раскрытие;
- после завершения открывается модальное окно с переходом дальше.

### Приблизить детали

Второй интерактив построен как режим внимательного просмотра:

- загружает `src/Kugach_picture_2.png`;
- позволяет перемещать изображение внутри viewport;
- поддерживает зум кнопками и колесом мыши;
- создает hotspots из JS-конфигурации;
- при клике на точку центрирует картину на выбранной детали;
- после просмотра всех точек открывает переход к финальному narrative-блоку.

## Работы Для Покупки

В прототипе есть отдельный экран `salesScreen`, который пока работает как frontend-MVP без отправки данных на сервер.

Реализовано:

- hero-блок страницы продаж;
- каталог доступных и зарезервированных работ;
- архив проданных работ;
- демонстрационный блок серии;
- детальный просмотр работы в модальном окне;
- нижняя форма заявки;
- модальная форма заявки из CTA на карточках;
- статусы `Доступна`, `Зарезервирована`, `Продана`;
- цены фиксированного типа и `Цена по запросу`;
- честное сообщение, что заявка не является оплатой или автоматическим резервом.

Изображения работ берутся из `src/for_sales/`.

## Как Запустить

Проект не требует сборки.

Базовый способ:

1. Открыть `index_masterskaya.html` в браузере.
2. Проверить первый экран, оба интерактива и страницу работ для покупки.

Локальный сервер не обязателен, потому что в проекте нет модульных импортов и backend. Если удобнее, можно открыть папку через любой статический сервер.

Важно: корневой HTML использует пути `src/...`. HTML-файлы внутри `experiments/` обычно используют `../src/...`, потому что лежат на уровень глубже.

## Проверки Текущего Этапа

После переноса мастерской-версии в корень были проверены:

- синтаксическая парсируемость HTML;
- баланс CSS-скобок;
- наличие всех уникальных `src/...` ассетов;
- корректные пути к `src/Kugach_picture_1.png` и `src/Kugach_picture_2.png` в интерактивах;
- отсутствие пропавших файлов среди ссылок на изображения.

Визуальная проверка через in-app browser не была выполнена: локальные `file://` и `localhost` URL блокировались политикой браузерной среды.
