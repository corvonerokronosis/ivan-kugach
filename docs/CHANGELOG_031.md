# Changelog 031: MVP страницы продаж работ Ивана Кугача

Дата: 2026-05-15

## Добавлено

- В `index.html` добавлен отдельный экран `salesScreen` для страницы продаж внутри текущего прототипа.
- На первом экране добавлены переходы к странице продаж:
  - кнопка `Работы для покупки` в hero-блоке;
  - отдельная карточка запуска `Работы для покупки`.
- На странице продаж добавлены основные MVP-разделы:
  - hero-блок `Галерея работ`;
  - краткий блок о художнике;
  - каталог доступных и зарезервированных работ;
  - демонстрационная структура страницы серии;
  - архив проданных работ;
  - нижняя форма заявки;
  - прототипные юридические блоки.
- Добавлен JS-массив `SALES_WORKS` с пятью работами из `src/for_sales/`.
- Добавлена поддержка двух типов цены:
  - фиксированная цена;
  - `Цена по запросу`.
- Добавлена поддержка статусов:
  - `Доступна`;
  - `Зарезервирована`;
  - `Продана`.
- Добавлены Open Graph и meta description для объединенного прототипа.

## Изменено

- Текст hero-блока страницы продаж обновлен:
  - `Заявочная галерея` заменено на `Галерея работ`;
  - вводный текст заменен на пользовательский текст о покупке работ, коллекциях и связи с художником.
- Детальный просмотр работы больше не является постоянным блоком на странице.
- Детальный просмотр теперь открывается во всплывающем окне при клике на карточку работы.
- Карточка работы преобразована из вложенной кнопки в кликабельный `article` с отдельной CTA-кнопкой внутри.
- Кнопки `Запросить покупку` / `Уточнить цену` в каталоге больше не открывают детальный просмотр.
- Кнопки `Запросить покупку` / `Уточнить цену` теперь открывают всплывающую форму заказа.
- Нижняя форма заявки оставлена на странице и продолжает работать как отдельный сценарий.

## UX-поведение

- Клик по любой части карточки, кроме CTA-кнопки, открывает детальный просмотр работы.
- Нажатие `Enter` или `Space` на карточке также открывает детальный просмотр.
- Детальный просмотр закрывается:
  - кнопкой `Закрыть`;
  - кликом по фону;
  - клавишей `Escape`.
- Всплывающая форма заказа открывается из CTA-кнопок каталога и из CTA внутри детального просмотра.
- Всплывающая форма автоматически подставляет выбранную работу.
- Для проданных работ CTA формулируется как интерес к похожим работам.
- Всплывающая форма заказа закрывается:
  - кнопкой `Закрыть`;
  - кликом по фону;
  - клавишей `Escape`.

## Формы и валидация

- Для нижней и всплывающей форм используется общая логика валидации.
- Обязательные условия:
  - имя заполнено;
  - указан email или телефон;
  - выбрана работа;
  - подтверждено согласие на обработку персональных данных.
- Обе формы показывают состояние ошибки или успешной подготовки заявки.
- MVP честно сообщает, что данные не отправляются на сервер.

## Проверки

- Проверен синтаксис inline JavaScript.
- Проверено отсутствие дубликатов `id`.
- Проверено, что все `document.getElementById(...)`-ссылки указывают на существующие элементы.
- Проверено наличие всех пяти изображений из MVP scope.
- Визуальная проверка через in-app browser не была выполнена из-за блокировки локального URL браузерной политикой.
